# 阿黔 · 每个团都有一位记得你的 AI 副导

> 贵客松 · 文旅赛道 · AI 副导 —— `#Guikesong`

阿黔是一款面向**贵州文旅跟团游**场景的「AI 副导」微信 H5 应用：真人导游负责带团与关键决策，阿黔负责**接住那些漏掉的信号**——集合信息、行程实时同步、按语言和兴趣陪讲、高频问答检索，以及「需要真人」时的异常预警与转交。

## 技术栈（技术选型与框架）

### 前端

| 选型 | 用途 |
| --- | --- |
| **Next.js 16**（App Router） | 服务端/客户端混合渲染、路由、API Route、Server Actions |
| **React 19** | 组件化 UI |
| **TypeScript 5** | 全量类型约束 |
| **Tailwind CSS v4** | 原子化样式、移动端优先、自定义主题令牌 |
| **SWR** | 游客端/导游端 2 秒轮询实时同步 |
| **lucide-react** | 线性图标 |

### 服务端 / 数据

| 选型 | 用途 |
| --- | --- |
| **better-sqlite3 + Drizzle ORM** | 本地 SQLite 持久化（旅行团/行程/成员/知识卡/故事卡） |
| **Zod** | 输入校验与类型推导 |
| **jose** | JWT 会话（导游、游客双身份，HttpOnly Cookie） |
| **高德地图 Web 服务 API** | 真实 POI 检索、驾车/步行路线、静态地图、真实道路行程图 |
| **腾讯位置服务** | 卫星底图 + 点位标记 |
| **阿里云百炼 qwen3.8-max** | 行程智能补全、文化讲解兜底（无来源不编造） |

## 核心能力

- **导游端驾驶舱**：建团（逐天行程 + 真实高德 POI）、行程编辑、异常预警、成员管理、数据复盘。
- **知识库（按团归属）**：导游预置「高频/重复问题」的 Q&A，游客问助手时按关键词检索命中；含文化故事、附近设施（洗手间等）、安全提醒。
- **今日提问明细**：来自真实对话，答不上的可一键「收录为知识卡」补答案。
- **故事卡 / 本团故事册**：只由真实「听过、答过、观察过」的内容生成，可分享、有源可溯。
- **路线图**：景区间驾车、景区内步行、今日景点卫星点位图三种形态。
- **安全边界**：集合时间/设施等事实只来自本团行程与已审核知识卡；密钥只存在服务端，绝不出现在浏览器。

## 目录结构

```
src/
  app/                 # 页面路由（封面 / 进团 / 游客端 / 导游端 / 故事卡）
  components/          # UI 组件（游客端、导游端、路线图、UI 基础件）
  lib/                 # 数据库、高德/腾讯、AI 规则、合约类型
  actions/             # Server Actions（建团、知识库、故事卡等）
public/                # 封面、演示图、海报等静态素材
seed/                  # SQLite 数据库文件（不随仓库提交）
```

## 快速开始

```bash
pnpm install
cp .env.example .env.local   # 按需填入高德/腾讯/千问 Key（本地演示可不填）
pnpm dev                     # http://localhost:3001
```

> 密钥与数据库数据不包含在本仓库内。部署时请使用 `.env.example` 中的占位说明自行配置，勿提交真实密钥。
